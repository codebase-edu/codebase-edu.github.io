# Lộ Trình Học Python Căn Bản

## 1. Hiểu Python Là Gì Và Cài Đặt Môi Trường
- **Mục tiêu học**: Hiểu Python là ngôn ngữ gì, tại sao nên học nó, và cài đặt môi trường phát triển.
- **Hoạt động**:
  - Tìm hiểu về Python (lịch sử, ưu điểm, ứng dụng thực tiễn).
  - Tải và cài đặt Python từ [python.org](https://www.python.org/).
  - Cài đặt IDE như PyCharm, Visual Studio Code hoặc Jupyter Notebook.
  - Học cách sử dụng terminal và IDE để chạy script Python.

---

## 2. Nắm Vững Cú Pháp Cơ Bản
- **Mục tiêu học**: Làm quen với cú pháp và cấu trúc Python.
- **Chủ đề cần học**:
  - Biến và kiểu dữ liệu (`int`, `float`, `str`, `bool`, `list`, `tuple`, `dict`, `set`).
  - Câu lệnh điều kiện (`if`, `elif`, `else`).
  - Vòng lặp (`for`, `while`).
  - Các câu lệnh cơ bản (`print`, `input`, `len`,...).
- **Thực hành**:
  - Viết chương trình máy tính cơ bản hoặc kiểm tra số chẵn/lẻ.

---

## 3. Hiểu Và Sử Dụng Hàm
- **Mục tiêu học**: Biết cách định nghĩa và sử dụng hàm trong Python.
- **Chủ đề cần học**:
  - Định nghĩa hàm với `def`.
  - Tham số và giá trị trả về.
  - Phạm vi biến (`global`, `local`).
- **Thực hành**:
  - Viết hàm tính toán đơn giản (VD: chuyển đổi nhiệt độ từ Celsius sang Fahrenheit).

---

## 4. Làm Việc Với Dữ Liệu
- **Mục tiêu học**: Biết cách xử lý và làm việc với các cấu trúc dữ liệu phổ biến.
- **Chủ đề cần học**:
  - List và các thao tác như thêm, xóa, sắp xếp.
  - Dictionary và cách truy xuất dữ liệu.
  - Xử lý chuỗi (chuỗi con, nối chuỗi, định dạng chuỗi).
- **Thực hành**:
  - Xây dựng chương trình quản lý danh sách học sinh.
  - Phân tích và xử lý chuỗi từ file văn bản.

---

## 5. Lập Trình Hướng Đối Tượng (OOP) Cơ Bản
- **Mục tiêu học**: Hiểu các khái niệm cơ bản của OOP và áp dụng trong Python.
- **Chủ đề cần học**:
  - Class và Object.
  - Thuộc tính và phương thức.
  - Nguyên lý cơ bản: kế thừa, đóng gói.
- **Thực hành**:
  - Xây dựng class mô phỏng tài khoản ngân hàng.

---

## 6. Làm Việc Với Tệp Và Xử Lý Ngoại Lệ
- **Mục tiêu học**: Biết cách làm việc với file và xử lý lỗi.
- **Chủ đề cần học**:
  - Đọc và ghi file.
  - Xử lý ngoại lệ (`try`, `except`, `finally`).
- **Thực hành**:
  - Viết chương trình đọc và lưu trữ dữ liệu từ file CSV.
  - Xử lý lỗi nhập liệu của người dùng.

---

## 7. Hiểu Về Thư Viện Và Module
- **Mục tiêu học**: Sử dụng các thư viện có sẵn và viết module riêng.
- **Chủ đề cần học**:
  - Import thư viện (`math`, `random`, `datetime`...).
  - Cài đặt thư viện bên ngoài bằng `pip`.
- **Thực hành**:
  - Tạo một game tung xúc xắc bằng thư viện `random`.

---

## 8. Làm Quen Với Dự Án Nhỏ
- **Mục tiêu học**: Kết hợp kiến thức đã học để làm dự án thực tế.
- **Ý tưởng dự án**:
  - Quản lý danh bạ điện thoại.
  - Game đoán số (guess the number).
  - Ứng dụng chuyển đổi tiền tệ.
